## [0.1.0] - 2026-10-09

### Added
- MCP server (`studiopilot-mcp`) with 6 tools: `scaffold_project`,
  `create_script`, `lint_luau`, `format_luau`, `validate_project`,
  `get_conventions`
- CLI (`studiopilot`) with `init` command: scaffolds a Rojo-structured
  Roblox project with AGENTS.md, Claude Code skills, and `.mcp.json`
- 4 Claude Code skills: luau-expert, roblox-data-model, roblox-ui,
  rojo-workflow
- Test suite covering templates and tools
- README, CONTRIBUTING, SECURITY, MIT license, CI workflow
